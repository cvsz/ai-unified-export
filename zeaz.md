# Applicable ZeaZDev Engineering Policy

Canonical policy: https://github.com/cvsz/zeaz/blob/main/zeaz.md

This exporter follows the canonical ZeaZDev AI & Engineering Operating Policy:
- Inspect → Understand → Plan → Validate → Apply → Test → Verify → Document.
- Least privilege, secure defaults, no secret collection, bounded execution and explicit timeouts.
- Local-first operation, no silent cloud/provider fallback, and no unauthorized external actions.
- Evidence-based status; skipped, blocked, failed and unverified checks remain visible.
- Minimal dependencies, reproducible output, resumable state, and operational documentation.

This project-specific summary does not replace the canonical policy. Read the canonical file and applicable repository instructions before making future changes.
